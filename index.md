## 4. Projects

### Project 1: Network Reconnaissance and Service Enumeration Using Nmap

This project demonstrates network reconnaissance, TCP SYN port scanning, and service version detection using Nmap.

The experiment was conducted in an isolated virtual laboratory using VMware Workstation, Kali Linux, and Metasploitable2. Both virtual machines were connected through a host-only network to ensure that all scanning activities were performed in a controlled environment.

The Nmap scan identified **23 open TCP ports**, including FTP, SSH, Telnet, HTTP, SMB, and database services. The results helped me understand how exposed services can be identified and how potential security risks can be assessed.

[View Nmap Project](projects/nmap-service-scan/)

### Project 2: TCP Three-Way Handshake Analysis Using Wireshark

This project demonstrates how TCP connections are established through the three-way handshake process using Python socket and Wireshark.

The experiment is conducted in a Kali Linux environment, where a local HTTP server and a Python socket client communicate through the loopback interface (`127.0.0.1`).

Wireshark is used to capture and analyse the SYN, SYN-ACK, and ACK packets, including TCP flags, source and destination ports, sequence numbers, and acknowledgement numbers.

The project aims to improve my understanding of TCP connection establishment and network packet analysis.

[View Wireshark Project](projects/wireshark-tcp-handshake/)

## 5. Learning Journey

During my cybersecurity studies, I have gradually developed a better understanding of network security through lectures and practical laboratory exercises. These activities have helped me connect theoretical knowledge with real cybersecurity tools and techniques. I have also realised that cybersecurity requires not only technical knowledge but also problem-solving skills, patience, and continuous learning.

One important learning experience was **network reconnaissance using Nmap**. In this laboratory, I used Kali Linux to scan a Metasploitable2 virtual machine in an isolated network environment. I practised host discovery, TCP SYN port scanning, and service version detection. The experiment identified 23 open TCP ports, including FTP, SSH, Telnet, HTTP, and database services. Through this activity, I learned how to identify exposed network services and understand their potential security risks. I also learned that discovering an open port does not necessarily mean a vulnerability has been confirmed, as further investigation is required.

Another valuable learning experience was **network traffic analysis using Wireshark**. This laboratory helped me understand how network communication works at the packet level, particularly the TCP three-way handshake. By observing SYN, SYN-ACK, and ACK packets, I was able to connect the theoretical concepts of TCP communication with actual network traffic. This improved my understanding of how connections are established and how packet analysis can support network troubleshooting and security investigations.

During my laboratory exercises, I also encountered technical difficulties. Configuring virtual machines and their network connections was sometimes challenging, especially when the machines could not communicate as expected. To troubleshoot these problems, I checked the network adapter settings, verified the IP addresses, and tested connectivity. This experience helped me understand the importance of checking basic network configurations before performing more advanced security tasks.

Although I have gained practical experience with several cybersecurity tools, I still find **network packet analysis and security programming** challenging. Understanding different protocols and interpreting complex packet information requires more practice. I also need to improve my Python programming skills to develop security tools more independently.

To improve my technical abilities, I have set a goal to **develop a simple Python-based network traffic analysis tool within the next few months**. The tool will analyse captured TCP packets and identify basic information such as source and destination IP addresses, ports, and TCP flags. I will measure my progress by testing the program against at least three sample packet captures, verifying the accuracy of its output using Wireshark, and documenting the results on GitHub.

Overall, these learning experiences have strengthened my interest in cybersecurity, particularly network security and incident response.
